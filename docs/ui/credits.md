# Photo credits /credits

Public, static server page, reached from the public portfolio footer. No login or model/database request. Uses the existing dark client palette, Instrument Serif display and Geist body. Source: the 24 photo records in `app/public/portfolio/imani/photos.json`.

Top to bottom: return link to `/c/imani`; Photo credits heading; explanation that Imani is a demonstration portfolio and does not claim authorship; disclosure that individual source/licence records were not all independently rechecked; ordered list of photo title, recorded photographer, source and recorded licence link. Morning Pour's record links CC0; the others link the recorded Unsplash terms. No claim that a demo invoice replaces the source licence. No developer ticket or placeholder instructions.

Desktop: 768px max reading column with 24px gutters. Phone: single column, wrapping source links. List rows separated by thin dividers, 24px padding; source links underlined and keyboard focus visible. No animation or interaction beyond navigation. Static content has no loading/empty/request error state; a failed external source navigation is handled by the destination. Do not imply the source metadata independently proves ownership or permission.

Skills: frontend-design preserves public identity; impeccable uses clear source labels and explicit uncertainty; apple-design keeps navigation immediate and motion restrained. Demo: footer opens readable credits rather than raw Markdown. Test checks every photo/source/licence record and the attribution disclosure.
