# Demo panel · `/demo` (batch 8)

**Purpose / viewer:** the creator, during the recorded demo only, shows renewal and expiry by moving time forward. Spec §5 "Demo control panel", §9 2:05-2:20.

## Behaviour
- Exists only with `DEMO_MODE=1`: the "Demo" nav item is added by the layout, and `GET /api/demo`, `POST /api/demo/clock`, `POST /api/demo/tick` answer 404 in live mode (the page then says the panel is off).
- Shows the demo clock date and how many days it is ahead of real time.
- **Advance to the next renewal** (primary, the only button): moves the clock forward (never back) to the start of the renewal window, end minus 7 days, of the creator's soonest active licence that has no renewal yet (seeded `SEED-DEMO-` licences never count, except Pinecrest Hotels · Harbor Light, `SEED-DEMO-RENEW-`, seeded to renew on camera), writes one `clock` ledger event, and runs the tick at once, so the ledger, pay page and receipts agree. When no window lies ahead it moves nothing and writes no event. Sits next to a Demo chip. Busy text while running; the result is one live sentence ("Clock moved forward 170 days to Apr 22, 2027. Tick: 1 renewal opened, 1 renewal invoice sent."). Seeded licences that end are named apart ("3 licences expired (2 of them seeded Demo)"). Under the sentence, "Open the renewal deal" links to the first renewal deal the tick opened or sent (B8 review fix 9).
- **Start a fresh deal** (outline, creator only, B9 9.2): `POST /api/demo/fresh-deal` adds or reuses a sample request, and only then resets the demo clock to real time (one `clock` event if it moved; a failed click leaves the clock alone). It adds one sample request through the normal intake, the first of print add-on, new photo social, billboard that Northwind has not already bought. A ready request goes to the agent as usual, so it may send an invoice. An unsettled sample deal (a request, or a quote with an unpaid invoice) is reused instead: no new request, agent run or invoice, and the result says so with "Open the deal". An unsettled billboard is reused only when it is the next sample, because it leaves only on a typed approval. Deletes nothing. The result sentence is followed by "Open the new deal".
- **Run tick again** (outline) replaces Advance while a tick is unfinished: the route answered 200 with `tickError`, or `GET /api/demo` says `tickPending` (due renewals, renewals to offer again or ended licences remain at this clock, read from the rows, so it survives a reload). It posts `/api/demo/tick`, which runs the tick and never moves the clock. `POST /api/demo/clock` answers 409 while a tick is pending.
- Help panel explains the button, the retry and that live mode ignores the clock.
- Creator only; the POSTs go through `guard()` (session + same origin).
